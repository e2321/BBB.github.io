# オンライン描画とプレイヤー識別

A/D動作では受信座標のYを遅れて追従させず、サーバーの速度・重力から最大100msの描画予測を行う。アニメーションも同じ時刻を使用し、接地したスナップショットではサーバーの床・設備上の高さに即座に合わせる。X/Z補間とモデル内の既存姿勢は分離して保持。Spaceの処理、オフラインの物理ルールは変更しない。着地の既存水しぶきはクライアント側で生成し、粒子は送信しない。

固定スロット0〜3に青・赤・緑・黄を割り当てる。サーバーがロビーと試合状態にcolorを含め、再接続・ホスト退出でも既存参加者の割当は維持する。魚の既存材質へ控えめなアクセントを重ね、虹色の発光が終了しても識別色は残る。名前プレートは幅・高さを1.5倍にし、文字の縁取り、遮蔽判定、距離制限を維持する。ゲーム表示はチュートリアルに統一。

公開にはフロントエンドとRenderサーバーの両方の更新が必要。Push・デプロイは実施していない。別PC2台と本番通信は未確認。
