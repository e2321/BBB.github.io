# 短いプロローグと2ステージ化

## 構成とクリア条件

プロローグの選択ボタンから、BBBと共通の魚・移動・Space・包丁・水分処理を使う短いチュートリアルが始まります。既存の魚とコックのGLB、アニメーション、効果音、木材表現、交互に置く3つの仕切りを再利用しています。

1. A/Dの交互入力による有効な着地を4回。Spaceや同じキーの連打では練習を飛ばせません。水分ゲージと水たまりの役割を2行で説明します。
2. Spaceで跳ねて着地を1回、大きな的への実際の包丁命中を1回。両方成立したら直ちに次へ進みます。包丁は何度でも投げ直せます。
3. 停止して死んだふりを一度行い、A/DかSpaceで解除。ゆっくり追うコック1体を避け、左右の矢印に沿った短いジグザグを抜け、奥の出口へ着地するとクリアです。

クリア時は「チュートリアルクリア！」とタイム・BPを表示し、「BBBで本番に挑戦！」で通常のステージ選択へ進みます。スキップはロビー・プレイ中・一時停止中に使用できます。プレイ中はEscで一時停止してボタンをクリックしてください。クリア済みフラグはローカルに保存し、起動時は従来どおりBBBを選択するため再プレイを強制しません。

練習の間はコックを停止し、的の練習中に自動で死んだふりしないようにしています。最後の区間のみ死んだふりと遅い追跡を有効にします。チュートリアルでは驚かせ失敗のBPペナルティを適用しません。BBB厨房の+500 / −1000 BPの駆け引きは維持しています。

## 所要時間の確認

| 確認方法 | 所要時間 |
| --- | --- |
| 操作を即実行する通し自動テスト | 約23.65秒 |
| 各段階で8秒ずつ説明を読む待ち時間を入れたシミュレーション | 約45.88秒 |
| ブラウザーでキー・マウス命中後にルートを自動操作 | 約24.5秒（起動後の待ちで多少変動） |

数値はゲーム内時間です。初見の人が1〜2分、慣れた人が45秒程度という目標の実プレイ評価は未実施です。操作を知っていればより早くクリアできます。進行を遅らせる強制待機時間はありません。

逃走区間の開始と出口の前後方向の距離は15.3m、旧脱出の開始から出口は約42.8mです。旧 `stage.js` / `simulation.js` / `kitchen.js` の長いコース・チェックポイント・称号処理は削除していません。新しいチュートリアル用の進行だけを別ファイルで追加し、旧コースは再利用・回帰検証に残しています。
