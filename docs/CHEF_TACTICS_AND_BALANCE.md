# 厨房の駆け引き・BBBバランス復元

追加指示による短縮プロローグとコンロ削除は [SHORT_TUTORIAL_UPDATE.md](SHORT_TUTORIAL_UPDATE.md) を参照してください。BBBはノーマル・厨房の2ステージです。

## 最終仕様と操作

- ノーマル・厨房とも3秒の「3→2→1→START!!」後に90秒の試合が開始します。開始前はA/Dでその場ビタンの姿勢と音だけを再生し、位置・HP・BP・コンボ・水分・アイテム・コックAI・試合時間は進みません。開始時には入力バッファと移動状態を消去します。
- A/D交互入力の消費は常に2%、Spaceは3%。BPコンボ倍率は維持。水たまりは既存3か所のまま、両BBBステージとも毎秒8%回復します。プロローグの回復・コース・進行は変更していません。
- 厨房のコック2体は魚全員を対象に独立して巡回・追跡します。近距離攻撃は0.75秒の構え後にHPを1減らし、3.2秒のクールダウンがあります。距離・高さ・設備による遮蔽を再確認するため、ジャンプや退避で避けられます。死亡は既存の刺身・5秒復活へ移行し、コックへBPは移りません。
- 止まると死んだふり。コックが確認し、油断した約0.8秒間にA/Dで解除、約0.4秒以内に実際のビタンを開始すると+500 BP。距離は1.5m以内。コック別に20秒の成功クールダウンがあります。
- 確認された近くのコックへのA/Dによる試みだけを判定し、早すぎる・遅すぎる・遠すぎる試みは−1000 BP（下限0）。一度の試みは一度だけ減点し、再挑戦は4秒間制限します。単なる解除、未確認の通常ビタン、Spaceによる逃走ジャンプは減点しません。
- 攻撃がすでに振り下ろされる段階では、目の前の死んだふりが間に合わない場合があります。確認を最後まで待てばコックをやり過ごせます。CPUも逃走・死んだふり・驚かせを選択します。
