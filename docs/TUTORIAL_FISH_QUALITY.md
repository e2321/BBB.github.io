# チュートリアル専用の魚の調整

変更は tutorial-view.js の操作魚 models[0] に限定。tutorial-fish.js がクローン済みの材質と専用コピーのジオメトリを調整する。CPU・オフラインBBB・オンラインBBBの生成処理、GLB、ルールは変更しない。

- 胴体中央を厚さ方向で最大14%、背腹方向で最大29%抑制。頭から尾まで連続した補正を適用。
- エラ、口、ヒレの付け根も同じ補正に追従。既存の膜、ヒレ筋、尾の形状、骨格アニメーションを再利用。
- 目を約12%拡大し、暗い瞳と落ち着いた虹彩を維持。
- 背中の暗い青、銀色の側面、白い腹を頂点色で滑らかにつなぐ。控えめな背中の模様と既存の微細な法線テクスチャを使用。
- 金属度0、肌の粗さ0.57、クリアコート0.12。ヒレは青灰色、膜の不透明度0.72。
- 接地中は変形後の表面をサンプリングして描画位置のみ補正。移動・ジャンプ・得点等の計算には触れない。
- 生成時だけ形状を調整し、フレームごとの再生成やメッシュ追加はしない。終了時に専用ジオメトリを破棄。
