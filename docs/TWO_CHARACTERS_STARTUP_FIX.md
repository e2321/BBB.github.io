# モデル初期化エラー修正・魚とイカへの整理

公開画面の「id is not defined」は、モデル生成ループで i を使いながら players[id] を参照していたことが原因。battle-view.js を players[i] に修正した。初期化中のReferenceErrorが共通catchによってモデル読み込みエラーとして表示されていた。

魚・イカの2種類へ統一。エビ・タコをモデル生成・カード・CPU割り当て・オンライン種類検証から除外した。保存済みの旧種類・旧サーバーからの種類は魚にフォールバック。画質とゲームルールは維持。

プレビュー生成失敗がゲーム起動を止めないようにし、finallyでレンダーターゲット・クリア色・アルファ・GPU資源を復元・解放。プレビューが表示できなくても名前ボタンで選択できる。モデル取得とゲーム初期化のエラー表示も区別する。

変更ファイル：battle-view.js、seafood-settings.js、seafood-model.js、seafood-menu.js、game.js、style.css、関連テスト。

検証：自動テスト141件＋サーバー20件。ノーマル・厨房・チュートリアルの実build処理で4匹生成を確認。Canvas/GPUは代替しているため実画面確認ではない。プレビュー例外後のレンダラー復元・選択・画質設定、旧選択の補正も検証。

Vite本番ビルド・Pages出力チェック成功。環境のパス権限問題を避けるため検証時だけpreserveSymlinksを指定。Vite/Pages/Renderのリポジトリ設定は変更していない。公開URLはこの環境から取得できず、本番の再確認は未実施。

Push・デプロイ未実施。公開反映にはPagesの更新が必要。オンラインCPUも2種類に揃えるにはサーバー更新も必要。
