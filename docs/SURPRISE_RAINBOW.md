# 厨房の奇襲成功報酬を強化

## 実装

- FEIGN_RULES.bonusを500→1000。倍率を掛けず、成功した瞬間に一度加算する。
- 50コンボ未満なら50コンボ、倍率3、継続期限の基準時刻を成功時刻に設定。既存rainbowイベントで音・虹色演出を再利用。既に50以上ならコンボ数・期限・演出を再設定せず1000BPだけ付与。
- 実際のA/D発動が可能になった時点で奇襲を判定し、その発動の水分消費・動作周期を計算する前にレインボーを適用。水分消費半減と通常比1.5倍の動きが最初の成功ビタンから有効。通常の着地では別途50BPを一度加算する。
- 入水時50ポイント回復・上限100、通常のコンボ終了（時間切れ、入水、死亡、死んだふりなど）を共有し、永久化しない。
- 成功クールダウンをコックごとの単一時刻から、魚ID別のrewardUntilへ変更。同じ魚・同じコックは20秒制限、別の魚・別のコックは独立。処理済みの起き上がり番号も魚ごとに保持し、二重加算を防ぐ。新試合では初期化する。
- コックの実状態は成功後すぐCHASINGへ戻り、攻撃タイマーを延長しない。既存3秒STUNNED停止を削除。表示側のみ0.65秒の既存Stunnedアニメーション・傾き・短い後ずさりを適用し、攻撃予備動作が始まればそのアニメーションを優先する。プロローグのコックモデル処理は変更していない。
- SURPRISE! +1000 BP、初回移行時RAINBOW!、既存の驚き音・ボーナス音を表示・再生。操作ガイドの報酬も更新。
- 認識→接近→確認→油断→解除→A/Dの条件、油断1.1秒・解除猶予0.6秒・成功距離1.8m、失敗−1000BP/下限0、Space逃走・普通の解除の減点免除を維持。

## 検証

ゲームテスト220件・サーバーテスト20件が全成功。追加した7テストで魚/イカ・人間/CPUの即時1000BPと50コンボ、初回からの消費半減/高速化、着地50BPとの分離と重複防止、既存レインボーの維持、通常の時間切れ/入水回復、同じコックに対する魚別クールダウン、20秒後の再取得、コックが停止せず攻撃すること、新試合リセット、通常ステージへの非適用、サーバー確定値のイベント/スナップショットを確認。

Vite本番ビルドとPagesアセット参照検査成功。既存の環境用ビルド補助スクリプトを使用。大きなバンドルの警告は残る。

実ブラウザでの驚きモーション・効果音の見え方/聞こえ方、複数PCの本番通信は未確認。厨房は現在オフラインのみで、オンラインの選択可能ステージは従来どおりノーマルのみ。厨房オンラインを新たに開放していない。サーバー共有シミュレーションのテストは厨房の実オンライン対戦検証とは区別する。

Push・GitHub Pages公開・Render再デプロイは実施していない。
