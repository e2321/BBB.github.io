# 4カテゴリガチャ・演出装備（2026-10-17）

## 排出内容と価格

今回から旧80/20方式と10連キャラクター保証を廃止。10連も通常抽選を独立に10回行います。
カテゴリを先に抽選し、その中から設定した相対重みで選びます。

- キャラクター15%：ヒトデ7.5%、タコ7.5%。魚・イカは初期所持なので排出しません。
- 武器35%：フォーク14%、おたま10.5%、フライ返し10.5%。包丁は初期所持。
- 水しぶき30%：虹色・泡・キラキラ・インク風が各7.5%。通常の水しぶきは初期所持。
- その他演出20%：プリズム軌跡・星の命中・祝福の紙吹雪・コンボネオンが各5%。各スロットの通常演出は初期所持。
- 単発100コイン／10連900コイン／重複1個50コイン返還。同じ10連内の重複も対象。

`gacha-config.js` に4枠それぞれのカテゴリ確率とアイテム相対重みを定義します。
合計100%・カテゴリ整合・登録済みアイテム・初期所持除外を検査し、無効な枠は抽選できません。
「海のなかまたち」のみ有効。深海・甲殻類・おもしろ海洋生物は維持し、実装済みアイテムのテーブルを登録するまで準備中です。

## 装備と保存

ホームの「装備」からキャラクター／投擲武器／水しぶき／投擲軌跡／命中／撃破／コンボの7項目を変更。
未所持は選択不可。変更は次の試合から反映し、死亡復帰で変更しません。
水しぶき・軌跡・命中・撃破・コンボ演出は装飾だけで、BP・水分・移動・HP・当たり判定を変更しません。
武器の既存性能差・ダメージ1・クールダウン検証を維持しています。

保存キー `bbb.collection.v1` を維持し、内部形式をversion 3へ移行。
version 1/2のコイン、キャラクター、武器、選択、請求済み報酬、抽選回数・履歴を維持し、
`ownedEffects` と `equippedEffects` を追加します。未所持・不正な装備はスロットごとの通常装備へ戻します。
モデルのキャッシュ／ダウンロード状態は所有データに含めません。抽選・結果表示だけでは3Dモデルをダウンロードしません。
キャラクター初獲得だけ金色の特別演出、武器・エフェクト・重複は通常演出。結果確定・保存後に演出し、スキップで再抽選しません。

## 演出の追加方法

1. `effect-registry.js` に一意のID・slot・name・styleを追加。slotは splash / trail / hit / kill / combo。
2. 未実装の描画スタイルなら `battle-particles.js`（水しぶき）、`combat-vfx.js`（軌跡・命中・撃破）、`battle-view.js` とCSS（コンボ）に対応する表示を実装。
3. `gacha-config.js` の対象プールにIDと相対重みを登録。抽選関数・装備保存処理を変更する必要はありません。
4. 下記の規則で任意のサムネイルを置き、既存テストに新IDの描画・所有テストを追加。

新キャラクターは既存の `character-registry.js` とモデル生成・遅延読込に登録してからガチャへ追加します。
テーブルに未登録・未実装・初期所持アイテムを入れると検査で無効化されます。

## 描画負荷とオンライン

既存の固定長InstancedMesh粒子・軌跡プールを再利用。水しぶきはオフライン最大160／オンライン48、
低画質では発生数を55%に削減し、遅いフレームではさらに削減。
戦闘演出の粒子プールは低画質32／通常80。通知・演出を新しい描画ループで再生しません。
寿命で非表示にし、試合のresetとviewのdisposeで既存リソース解放処理を使用します。

演出IDだけをサーバーでスロット別に検証してメンバーに保持し、ロビー・試合状態で同期します。
粒子の個別位置は通信せず、クライアント側で再生。試合中の装備変更は拒否し、リスポーン・再戦でも保持。
装飾の所持は既存と同じブラウザ保存であり、サーバー発行の所有証明ではありません。
攻撃や報酬の処理はサーバー主導のままです。

**既存の未解決事項：新武器のオンライン使用は信頼できる所持証明が未実装のため、サーバーが包丁へ戻します。**
今回この制限を自己申告による解放で回避していません。武器の装備と性能差はソロで利用できます。

## 開発者モード

既存パスワード入力→サーバー一致判定→管理メニューを直接表示する流れを維持。
追加承認、メール認証、アカウント登録はありません。
公開サーバーの `BBB_ADMIN_PASSWORD` に指定の値を設定してください。秘密値はフロント・本書に含めません。
成功時は15分の管理セッションを発行し、各操作をサーバーで認証。失敗時エラー、試行回数制限、ログアウト失効を維持。
Renderの設定値や今回のコードの本番反映は未確認・未実施です。

- ガチャ：カテゴリ確率確認、100回／1000回などのシミュレーションと設定率・実測率表示。
- 全エフェクトTEST解放、TEST装備、全IDごとの実際の描画プレビュー。
- キャラクター初獲得／重複／武器／水しぶき／その他のガチャ演出を個別テスト。
- 低画質固定の独立TESTを起動し、水しぶきと戦闘粒子を100回発生させる負荷テスト。
- パフォーマンス画面で現在のFPS・描画数・GPU資源数を確認。
- 既存のキャラクター・武器・モデル取得失敗・ゲームプレイTESTを維持。

通常のコイン・所持・統計はTESTから変更しません。低画質TESTも通常設定の保存値を書き換えません。

## 検証

自動テストでカテゴリ境界・分布・保証なしの10連・重複返還・保存移行・装備制限・画像失敗代替を検証。
固定長プールの再利用・寿命・低画質削減・演出からゲーム状態を変更しないこと、サーバーのスロット検証・再戦保持・管理者認証も検証。
10万回抽選の実測：キャラクター14.814%、武器35.421%、水しぶき29.922%、その他19.843%。
10連1万組の実測はキャラクター15.015%、キャラクターなし1907組。確定保証はありません。
ブラウザE2EはEdge起動時の終了により実行不可。PC・スマホ・タブレット実機、複数端末、Render本番通信・実測FPSは未確認。
ビルドとPages相対パス・モデル検査の実行結果は最終報告を参照。
