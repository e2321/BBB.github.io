# ホーム・自由設定ソロランク・ガチャ・装備統合（2026-10-17）

今回の指示に対応する最新仕様です。過去の `SOLO_RANK_AND_FIXES.md` の「通常ソロ／ランク戦の分離」「コック2体・ライフ3固定」「旧RP表」は本書の内容に置き換わります。

## ホームと開始方法

- 中央に選択キャラクター、下に現在のモード・説明・大きな「プレイ！」を表示。
- 「モード変更」または現在モードのパネルから、クイックマッチ／友達対戦／ソロ対戦／チュートリアルを選択。選択だけでは開始しません。
- チュートリアルはプレイで直接開始。ソロは対戦準備画面で設定確認後「開始」。オンラインは既存の接続・マッチング／友達ルーム画面へ進みます。
- モード選択と対戦準備は独立したダイアログです。設定画面は対戦準備画面より手前に表示します。
- 前回のモードを `bbb.homeMode.v1` に保存。初回のみチュートリアル。旧通常ソロ／ソロランクのIDはBATTLEに集約。
- 独立した「カスタマイズ」「称号」ボタンを除き、「装備」に統合。機能と既存の保存データは残します。

## ソロ対戦と報酬

すべての通常プレイヤーのソロ対戦をランク対象に統一しました。チュートリアル・オンライン・独立した開発者TEST試合は対象外です。

- 標準は人間1＋CPU3、厨房、90秒、コック2体、ライフ3。
- コック0〜3、最大ライフ1〜4を自由に設定可能。CPU数の選択UIは元からないため追加せず3体のまま。
- ランク境界：ブロンズ0、シルバー100、ゴールド250、プラチナ450、ダイヤモンド700、マスター1000 RP。1000を超えて蓄積できます。
- 4人時のRP：1位+40、2位+20、3位0、4位−5。同BPは競技順位で同じ報酬。
- RP下限0。昇格した試合の**次の3試合**で、そのランクの最低RPを保護。保護終了後は通常の減算。最高到達ランクは降格しても保持。
- 途中退出は従来の−20 RP・コインなし。降格保護が残っていればランク下限を適用。
- CPU難易度：0.75／0.85／1.0／1.15／1.3／1.45。索敵、反応、命中のばらつき、攻撃判断、コンボ継続、水分管理、回避などAI判断のみ調整。魚の基本速度・ダメージ・HPをランクで強化しません。
- 完走コイン：20／25／30／40／50／60。1位追加：10／15／20／25／35／40。
- 設定補正：コック0体×0.75、1体×0.9、2体×1、3体×1.1。HPは全員共通で変わるため補正なし。
- RPの正の加算とコインに設定補正を適用し、整数へ四捨五入。負のRPは簡単な設定で軽減しません。例：ブロンズ・コック0・1位は+30 RP、23コイン。
- ランクと設定は試合開始時に固定。設定変更だけでは報酬を発生させません。
- 将来の少人数にも報酬関数で対応：順位を1〜4へ正規化し、3人×0.9、2人×0.75、1人はRP・コインなし。総補正は0.5〜1.2に制限。現行ソロは常に4匹です。
- 無操作放置には正のRP・試合コインなし。実移動と複数時間帯の有効着地、または命中を使う既存の活動検証を維持。
- 試合IDで結果を一度だけ保存し、コイン保存失敗時の再送も同じ付与IDで重複防止。旧通常ソロ報酬との二重付与なし。
- 結果画面に順位・BP・RP増減・現在RP・コイン・昇降格・次ランクまでのRP・降格保護残数を表示。

## ガチャ

- 排出とコイン保存を先に確定。その後フルスクリーン演出を開始します。
- 通常単発7秒、キャラクター単発9秒、10連10秒。シンク導入→水の揺れ→光→実物プレビュー→結果一覧。
- スキップ可能。スキップしても再抽選しません。結果は「結果を閉じる」まで保持し、10枚のカードから個別詳細を確認可能。
- NEW／所持済み／50コイン返還／カテゴリを表示。キャラクターは特別な背景・光・効果音。
- 二重クリック防止、画面遷移時の古い非同期結果の破棄、タイマー解除、プレビュー解放を実装。
- 価格は100／900、重複50返還、10連カテゴリ保証なしを維持。
- キャラクター15%／武器35%／水しぶき30%／その他演出20%を維持。未実装・初期所持品を抽選対象から除き、候補がないカテゴリは残るカテゴリへ比率を再配分。全候補なし／設定不正ならそのガチャのみ停止。
- 海のなかまたち以外の3ガチャは、候補が未実装のため準備中のまま。架空アイテムは追加していません。
- バナーは `gacha-config.js` の `banner` で指定。既存の実画像 `ocean.png`、`deepsea.png`、`crustacean.jpg`、`funny.jpg` を保持し、BASE_URL経由で表示。将来ユーザーがWebPを置いた場合は対応する設定名を変更できます。画像の生成・拡張子だけの偽装はしません。欠落時は名前の代替バナー。

## 装備

- 上部5タブ：キャラクター／武器／水しぶき／演出／称号。
- 演出タブの内部：投擲軌跡／命中／撃破／コンボの4枠。
- PCは4列＋右側詳細、スマホは2〜3列＋下部詳細、タブは横スクロール。Safe Areaと縦スクロールに対応するCSSを実装。
- 所持・未所持・装備中・レアリティを表示。選択カードは金色。未所持の詳細は見られますが装備は禁止。
- 選択品だけ実モデル／実エフェクトを描画。未所持でモデル未取得の場合は明確な代替表示。所持レアモデルは選択時に遅延取得。
- 武器は共通ダメージと弾速・判定・間隔の倍率を表示。既存武器性能は変更なし。
- 称号は解除条件と大きな文字を表示し、ホームにも装備称号を反映。
- 実績カラー・実績エフェクトはキャラクター詳細に統合。通常水しぶきと併用する従来実績エフェクトの優先関係も保持。
- 新しい描画ループやWebGLコンテキストは追加せず、既存のメニュー用rendererとアプリの単一RAFを再利用。選択プレビューは約12fps、低画質の粒子プールは通常の半分。閉じると停止・解放。対戦準備や開発者画面の背後ではホームの3Dプレビューも停止。
- ゲームの物理・BP・命中判定にプレビューや装飾処理は関与しません。

## 実績・データ移行・開発者TEST

- 既存39実績・15称号は維持し、ソロ10／50／100勝の3実績を追加（計42）。従来の総合10／50／100勝と異なり、オンライン勝利では解除されません。既存ソロ勝利数から遡って解除できます。
- ランク保存はキーを維持したまま内部version1→2へ移行。RP・最高ランク・過去結果は保持し、降格保護を追加。現在ランクと次境界も保存。
- コイン・所持品・装備・実績・称号・統計・ソロ設定の既存保存キーは変更しません。所持とモデル取得状態は分離したままです。
- 端末内ソロランクであり、改ざん耐性のある公式オンラインランキングではありません。
- 開発者TESTに降格保護・0.75難易度・新RP計算・フルスクリーン単発／10連・5カテゴリ装備プレビューを追加。TESTの称号操作も通常プロフィールと分離。
- 認証は既存のサーバー側環境変数照合・15分セッション・操作ごとの権限確認を維持。パスワードをフロントエンドへ追加していません。

## 検証結果

- フロント自動テスト：353件成功。
- サーバー自動テスト：46件成功。人数・CPU補充・連戦・切断復帰・共有ルール・管理者セッションの既存検証を含みます。
- 追加検証：昇格後ちょうど3試合の保護、設定の開始時固定、少人数順位正規化、旧ランク保存移行、ソロ勝利数の分離、空カテゴリの安全な正規化、演出スキップ・結果保持・遅延結果の破棄、固定長プレビューと解放。
- Vite本番ビルド成功。Pages検査成功：相対エントリ、埋め込みモデル、ローカル絶対パスの不在、同梱依存を確認。
- このWindows環境では通常のVite実行がパス解決制約に当たるため、既存のビルド用補助スクリプトから `preserveSymlinks:true` を指定して同じVite設定・本番WSS環境変数でビルド。Vite設定・公開ワークフローは変更していません。
- ブラウザテストも試行しましたが、Edgeがページを開く前に終了（Target closed／TransactNamedPipeエラー）。そのため今回のPC・スマホ・タブレット実表示、WebGL/FPS、実サーバーへの複数端末接続は未確認です。
- 最新導線に関わるホーム・ガチャ・武器装備・ソロのブラウザテストを更新しました。過去の旧ステージ・旧UI専用ブラウザシナリオ一式の再調整・一括検証は未実施です。
- 本番ビルドには既存の大きいチャンクの警告あり（JS約988KB、gzip約287KB）。既存魚モデル約44MBを含む配布全体は約70MB。今回モデル自体は増やしていません。実端末の負荷低下／向上は計測できていません。

## 公開と残る確認

- GitHubへのpush、GitHub Pages公開、Render再デプロイは行っていません。
- オンラインのルーム・クイックマッチ・再戦の通信仕様は変更なし。管理者の新TEST項目はサーバー側更新が必要なので、将来公開する際は管理者コードと共有のranked/gacha関連ファイルもRenderへ反映してください。
