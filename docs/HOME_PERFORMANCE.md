# ホーム画面の軽量化

## 変更

- ホーム・試合開始前・オンラインロビーの静止背景は、画面遷移、操作、サイズ変更、WebGL復旧時だけ再描画する。待機中はモデル・カメラ・影・非表示HUD・ミニマップの連続更新を止める。
- 既存の描画ループは1本のまま維持する。試合中は従来どおり毎フレーム更新し、ホーム待機時間を試合開始直後の経過時間へ加算しない。
- キャラクター選択の小さなカード画像は、実際の魚・イカモデルを軽量設定で1回ずつ描画して再利用する。ゲームの画質設定を変えてもカード画像を再生成しない。
- 選択キャラクター、ゲームの画質設定と保存、モデル、ルール、CPU、通信、ロビー維持・再戦は変更しない。添付文書のライフ・水分・BPなどの調整は今回のホーム軽量化には含めていない。

## 検証

- 自動テスト176件成功。静止ホームで600フレーム分の再描画を省けること、変更時の1回の再描画、ゲーム中の連続描画、非表示からの復帰、画質変更時のカード再生成が0回であることを検証。
- Vite本番ビルド・GitHub Pages参照検査成功。ビルドは既存の検証用preserveSymlinks指定で実施し、公開設定は変更していない。既存のバンドルサイズ警告は残る。
- ブラウザ用にも、待機中の描画回数・画質変更・試合開始後の連続描画を確認するテストを追加。ただしEdgeが起動時に終了する環境エラーで実行できなかった。実画面・GPU使用率・消費電力・実機オンライン再戦は未確認。FPSや負荷改善率の実測値は報告していない。
- Push・デプロイは未実施。
