# ホーム・チュートリアル・開発者モード改修（2026-10-17）

## 実装

ホームは上部にタイトル／コイン、中央に選択中の3Dキャラクター、周辺にガチャ・キャラクター・実績・称号・統計・設定、下部に「モード選択」を配置しました。所持キャラクターを左右の矢印で巡回し、選択を既存の保存先へ保存します。未選択モデルの一括ダウンロードは行いません。低／通常の画質がプレビューにも反映され、描画用モデルとバッファの変更は設定変更時だけです。プレビューは既存フレームループに従い最大12Hz、動きを軽減する設定にも対応します。

モード選択は独立したダイアログです。クイック・友達・ソロ・チュートリアルの既存処理へ接続し、閉じる／背景クリック／Esc／キーボードのフォーカス移動に対応します。初期フォーカスはチュートリアルですが、自動開始しません。接続待ち、オンラインのロビー復帰、ソロ再戦時もこのダイアログ内に表示します。設定値、2桁コード、待機時間、CPU補充のルールは変更しません。

スマホ／タブレットのチュートリアルでは本文13px、見出し14px、補足12px、ボタン12pxに整理しました。補足は「くわしい説明」で開閉でき、パネルは画面高さの最大30%かつ既存のボタン回避レイアウト内に収まるようスクロールします。PCの説明は展開表示です。画面幅だけでなく既存のタッチ判定を利用し、ジャンプ・移動スティック・死んだふりボタンは追加していません。

後半は、実際のコックAIによる奇襲→虹色→実際の水たまり入場時の+50回復→最終30コンボ・100BPに変更しました。最終課題は回復を済ませてから完了します。PCは実際の操作、モバイルは既存の奇襲実演を使用します。水分消費は直前の明示指示を優先して虹色中0.6ポイントを維持し、説明も「半減」ではなく0.6と表示します。敵撃破は完了条件ではありません。

## 開発者モードの使い方

1. ホームの「設定」→「開発者モード」。伏せ字入力／表示切替／Enter認証／キャンセルに対応。
2. サーバー認証後、ガチャ・キャラクター・ゲームプレイ・パフォーマンスを選択。
3. ゲームプレイは「ローカルTEST開始」から独立したローカル対戦へ。下のTESTバーでメニューに戻り、調整後「TESTへ戻る」で再開。奇襲テストは検証位置へ配置するもので、成功報酬を無条件に付与しません。止まって油断を待ち、既存の奇襲判定を試せます。
4. 「開発者モード終了」でサーバートークンを失効し、通常ホームへ戻ります。15分経過でも失効します。通信が途切れて失効要求を届けられない場合は明示し、ローカル権限を破棄、サーバーセッションは期限で終了します。

TESTコインは+100／1000／10000／任意値、残高リセットに対応。1回／10回抽選と100回／1000回シミュレーションは通常と同じ `drawCharacter` 関数を利用し、大量抽選ではモデルを取得しません。実測排出数・率と設定率を表示します。

TEST所持は個別／全解放、初期化、選択、モデルの状態と再取得、読み込み失敗の模擬、未所持敵の魚代替確認に対応。モデルキャッシュも通常とは別です。BP／コンボ／水分／HP／虹色／コック人数／100件のBP通知をローカルTESTで操作できます。正式オンラインのルームを変更する管理APIは用意していません。

FPS、実際の描画対象オブジェクト、renderer.infoのドローコール／三角形／ジオメトリ／テクスチャ、読み込み状態／参照数、BP通知数、通信状態、ループ数を手動更新できます。ホームや停止中のFPSは直前の測定値です。

通常のコイン・所持・実績・統計には書き込みません。TESTの財布はサーバーの管理セッション内だけに存在し、モデル表示にも別のキャッシュを使用。通常の対戦記録処理は `testSession` のとき呼び出しません。TEST初期化で通常のデータを消しません。

## 起動と秘密情報

ゲーム本体のフォルダ `C:\Users\shota\game-project\BBB` で `npm run dev:all`。ViteとColyseusを同時起動します。既に起動している場合は一度終了してから再起動してください。既存の個別起動コマンドも利用できます。

フロントは `.env.local` の `VITE_ONLINE_SERVER_URL=ws://localhost:2567` を使用。サーバーは開発時だけ `server/.env.local` を読み込みます。指定された初期パスワードはこのGit無視ファイルに設定済みです。本文・ソース・テンプレート・ビルドにパスワードそのものは記載しません。

公開時はRenderの `bbb-friends-server` → Environment に **BBB_ADMIN_PASSWORD** を追加し、指定したパスワードを値として設定してください。VITE_を付けてはいけません。`render.yaml` は値を含まない `sync: false` 宣言のみ追加しています。既存サービスへの反映はRenderで設定してサーバーを再デプロイする必要があります。**今回、外部設定変更・push・デプロイは実行していません。** サーバーが未更新／パスワード未設定の場合は理由を表示して認証を拒否します。

管理通信はHTTPS（開発時のloopback HTTPのみ例外）、既存の厳密なOrigin許可を使用。パスワードの一致判定はハッシュと一定時間比較、ログインはIPごとに1分5回、管理操作はセッションごとに1分180回まで。トークンは暗号学的乱数・15分期限で、ブラウザのlocalStorageに保存しません。毎回サーバーで検証し、ログアウトで破棄します。Render以外のプロキシに移す場合はTLS終端判定を別途構成してください。

通常コイン・所持の既存ローカル保存方式をサーバーDBへ移行した改修ではありません。開発者の認証セッション、テスト用財布、正式なプレイヤー記録を混同しない構成です。
