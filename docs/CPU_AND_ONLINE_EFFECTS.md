# CPU微調整とオンライン水しぶき停止

CPUは加速効率1→0.9、通常BP効率1→0.9、攻撃頻度1→0.85、判断間隔0.16→0.20秒、旋回3→2.8、交互入力間隔0.13→0.15秒、照準の誤差0.09→0.12（上下0.06→0.08）。首位を狙う方針、補給、脱出、HPなどは維持。ノーマル・厨房・オンラインCPU補充は同じ定数を利用。人間プレイヤーには適用しない。

オンライン専用の描画フラグで水滴160個と波紋16個のプール・描画オブジェクトを作成しない。発生処理と水しぶきの行列・色更新も行わない。小さなHP回復ハートのみ保持し、非活動中は更新を省略。オフラインの水しぶきと水面表現は維持。通信する粒子は引き続き存在しない。

実機2台・本番サーバーと指定PCでのFPS比較は未確認。公開反映にはフロントエンドとサーバー双方の更新が必要。Push・デプロイは実施していない。
