# オンラインA/D接地修正

他プレイヤーのA/D動作だけに100msの描画履歴を使用。位置、向き、左右、アニメーション位相を同じ履歴の時刻から再現する。受信履歴は魚ごとに最大12件。過去パケットで描画を巻き戻さず、Spaceとローカルプレイヤーの予測は変更しない。

サーバーのジャンプ・着地イベントにゲーム時刻、左右、周期、向きを含め、着地の水しぶきを同じ描画時刻で一度再生する。粒子自体は同期しない。既存の粒子プールを再利用する。

他プレイヤーが接地しているA/D姿勢のみ、変形後の代表頂点と床の高さを比較し描画モデルの高さを補正する。各モデルの頂点サンプルは初回に作成し使い回す。ゲームの座標、移動速度、BP、Spaceの軌道、オフラインの描画には補正を適用しない。頂点サンプルは軽量な近似なので全頂点の厳密な接触判定ではない。

チュートリアル名称、1.5倍の名前プレート、サーバー割当の青赤緑黄は既存の修正を維持し二重適用しない。虹色終了後も識別色を維持するブラウザーテストを追加。
