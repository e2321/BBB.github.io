# NEON AQUA ARCADE：ホーム刷新（2026-10-17）

## デザインと配置

- 深いネイビー、シアンの光、青紫の差し色、黄色のプレイボタンに統一。
- ヘッダーはタイトル、PC／スマホ対応表示、コイン残高。中央は左のキャラクターと右のモード・RP・開始操作。下部はガチャ／実績／戦績・統計／装備／設定の5項目。
- 旧ホームの水玉背景、大きなキャラクター用カード、太い白枠・黒い段差影・均一なボタンを、新しいホームでは使用しません。
- キャラクターの背景は淡い発光、楕円の接地リング、柔らかな影。モデルの形状・テクスチャ・ゲーム内アニメーション自体は変更なし。
- 通常画質の背景には2枚のCSS合成レイヤーでゆっくりした泡と光の筋。新しい常時3D粒子はありません。
- モード情報は右の半透明パネルに集約し、モード変更は軽い文字ボタン、開始は黄色〜オレンジの大きなボタンに分けました。
- 下部のアイコンは統一した線幅のインラインSVG。画像・アイコンライブラリの追加通信なし。
- 既存のモード選択、装備、設定などのダイアログも、薄い境界・深い背景・控えめなガラス表現へ調整。
- フォントはローカルの日本語フォントを優先。見出し・本文・数値の太さと字間を分け、フォント配信サービスへのアクセスは増やしていません。

## キャラクターと操作感

- 選択モデルは左に大きく表示し、待機時の上下移動と回転をゆっくり再生。
- ホーム専用のカメラ距離を調整し、既存メニューレンダラーを透過背景に。補助光を1灯追加して輪郭を見せます。ゲーム本体のrendererや照明には影響しません。
- ホームのモデル上でマウスを動かすと、最大約20度の小さな見回し。タッチはスクロールを優先し、ドラッグで視点入力を奪いません。
- キャラクター変更は360msの移動・拡大、モード変更は240ms、パネル表示は240ms。ホバー150ms、押下90msを基本にしています。
- プレイ押下時は固定の6個のDOM水滴で短い演出。メッシュ・パーティクルの増殖なし。
- UIの選択／開始に短い専用音を既存Web Audio合成へ追加。既存マスター音量・ミュート・8音の上限を維持し、UI入力には110msの抑制も適用。
- 対応端末のタッチ入力のみ、4〜9msの短い振動。動きを減らす設定では振動も抑止。

## スマホとスクロール

- PCは左右2カラム。スマホ縦画面では縦配置、横画面では小さな2カラムを維持。
- 小さい横画面ではヘッダー・プレビュー・余白を圧縮し、全項目へ縦スクロール可能。
- Safe Area、画面幅の制約、フォーカスの視認性、ボタンのタップ領域を維持。
- モード選択画面に開始ボタンは追加していません。モードを選んだだけでは試合は始まりません。

## 負荷と既存機能

- 通常／低の2設定と低画質の初期値を維持。
- 低画質では背景の常時アニメーションとガラスぼかしを停止。ホームのモデルは低8fps／通常12fpsに制限。
- 既存のメニュー用renderer・モデルを再利用。新しいWebGLコンテキスト、requestAnimationFrame、ポストプロセスは追加していません。
- 画面を閉じる・別メニューを開く・ブラウザが非表示になると背景の常時演出を停止。prefers-reduced-motionと既存の「アニメーションを軽減」に対応。
- UI用の新しい音声サンプルは短い合成音のみ。新規の画像・3Dモデル・フォント通信はありません。
- 8fpsは従来の12fpsに対してホーム描画回数を約33%減らす設定上の値です。実機FPS・GPU使用率の改善率は測定できていません。
- キャラクター選択、称号、コイン、共有ガチャ、動画、ソロランク、オンライン、友達ルーム、チュートリアル、装備、開発者認証を維持。ゲームルール・当たり判定・CPU・オンライン通信処理は変更していません。

## 検証結果

- フロントの自動テスト：363件成功。
- サーバーの自動テスト：54件成功。
- 新規検証：必要なIDと5つのメニュー、2カラム構造、画質・動きを減らす指定、UI音の長さとゲイン、入力の抑制、6個の水滴の再利用と破棄、マウス見回しでモデルを再生成しないこと。
- Viteの本番ビルドとPagesの相対パス・アセット検査に成功。既存の大きいJSチャンクの警告は残ります。
- PC1440×900、スマホ横844×390／568×320、縦390×844、タブレット1024×768の実CSSを使うブラウザテストを追加。
- ブラウザテストは実行を試みましたが、Edgeがページを開く前にTarget closed／TransactNamedPipeエラーで終了。したがって**実画面の配置・折り返し・色・ホバー・スワイプ・動画再生・実機FPSは未確認**です。スクリーンショットを確認済みとはしていません。
- ローカルで確認するには `npm.cmd run dev:all` で表示されたURLを開き、必要に応じて `npx.cmd playwright test tests/neon-home.browser.js tests/home-scroll.browser.js` を実行してください。
