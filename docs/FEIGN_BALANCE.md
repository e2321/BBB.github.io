# 厨房の死んだふりボーナスを少し緩和

成功には従来どおり、死んだふり→コックの接近・確認→油断→解除→A/Dのビタンが必要。

- 油断中の成功可能時間：0.8秒→1.1秒
- 解除後のビタン猶予：0.4秒→0.6秒
- 成功距離：1.5m→1.8m
