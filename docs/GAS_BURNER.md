# イカの反り・ソロCPU選択・レインボー得点・ガスバーナー

## 実装

- イカのみ、A/Dの曲げ振幅を約2倍にし、ため・短い保持・伸展・余韻を追加。胴体中央が両端より上がる骨格変形を全画質に適用。8腕・2触腕の既存の遅延を維持。魚のモデル・アニメーションとSpaceの物理は変更なし。
- ソロ開始時、魚選択ならCPUは全員魚。イカ選択ならCPUごとに独立した2択。抽選はゲーム用乱数を消費しない。再戦時に再抽選し、オンラインのCPU選択は変更しない。
- 50コンボ目からA/Dの有効着地は一律50BP。CPUも同額。通常加点と重複しない。Spaceの通常計算・低水分時の減点・コンボ解除は維持。
- ノーマルと厨房にガスバーナーを各2個配置。接触で自動点火、10秒継続、再取得は残り10秒へ更新。取得地点は15秒で再出現。チュートリアルには配置しない。
- 炎は進行方向の前方約3.8m、半角0.28rad。地形の遮蔽を判定。描画も同じ方向・距離・遮蔽関数を使用。継続接触1.5秒ごとに1HP、離脱や無敵中は蓄積をリセット。同時に複数の炎を受けても蓄積速度は増やさない。対象ごとに管理し、ダメージ時に接触中の攻撃元へ既存のキル処理を適用。
- 炎による致死ダメージだけ、被害者へ「焼き魚になりました。」を表示。通常の死亡・刺身・4秒後の復活・5%BP奪取を再利用。
- CPUは近いバーナーへ向かい、噴射中は相手へ接近。炎に接触したら逃走し、水分回復やコック対応より優先。判断更新は既存の0.2秒周期を使用し、速度・攻撃頻度などの定数は維持。
- 炎のメッシュは事前作成し再利用。軽量/標準/高画質で3/5/9本の描画帯を使用。音は既存Web Audioの音量制限・コンプレッサーにつなぐループ1本。噴射終了・死亡・通信断・結果・ロビー復帰・画面破棄で停止。
- オンラインの取得・噴射時刻・ダメージ・死亡原因はサーバーで確定。クライアントはスナップショットから描画のみ。関節や炎の粒子を送信しない。再戦でアイテムと効果を初期化。ルームコード・名前・色・CPU補充設定の既存処理は維持。

主な調整値は `gas-burner.js` の `GAS_BURNER_DURATION`、`GAS_BURNER_DAMAGE_INTERVAL`、`GAS_BURNER_RULES` と、`battle-rules.js` の `RAINBOW_LANDING_BP`。

## 変更ファイル

- `squid-motion.js`：イカの骨格変形
- `battle-simulation.js`、`battle-rules.js`：ソロCPU抽選、50BP、既存ダメージとの統合
- `gas-burner.js`（追加）：共通アイテム・炎・遮蔽・継続ダメージ
- `battle-stages.js`：バーナー配置
- `battle-ai.js`：取得・照準・危険回避
- `burner-presentation.js`（追加）：アイテム、炎、残り時間
- `wet-audio.js`：噴射ループ音
- `battle-view.js`、`online-view.js`：描画、死亡メッセージ、同期
- `game.js`：ロビーへ戻る際の音停止
- `server/src/session.js`：状態送信、切断時の消火
- `tests/gas-burner.test.js`、`tests/burner-presentation.test.js`（追加）、`tests/squid-motion.test.js`：ルール・描画構造・反りの検証
- `server/tests/gas-burner.test.js`（追加）：サーバー判定・切断・再戦

同名ファイルを親フォルダーの開発用ミラーにも反映。

## 確認と制限

自動テストは全163件、サーバーテストは全22件を実行。新規テストでは取得競合、10秒、1.5秒、離脱、30/60/120Hzの一致、遮蔽、無敵、重複炎、死亡原因、5%奪取、再出現、切断、再戦、50/51コンボ、CPU抽選、全画質の中央の反り・描画オブジェクト再利用を確認。

Vite公開用ビルド・Pagesアセット検査を実行。実行環境のrealpath制限の回避として、検証時のみ `resolve.preserveSymlinks=true` を使用。既存のVite設定・GitHub Actions・Render設定は変更なし。

ブラウザテストはEdge起動時の `Target page, context or browser has been closed` で実行できなかった。実画面の炎・音・イカの自然さ・FPS・点滅、2台でのオンライン表示、本番通信は未確認。描画ループやrenderer/canvasの生成処理には変更を加えていないが、点滅が起きないと実証したものではない。

GitHubへのpushおよびRender/Pagesへのデプロイは未実施。公開へ反映する場合はフロントとサーバー両方の更新が必要。
