# ビタンビタンエリア廃止

## 変更内容

- ノーマル・厨房の中央エリア定義、接触判定、2倍BP、レインボー70BP、入場イベント、プレイヤーのエリア内状態を削除。
- 境界リング、発光看板「BP×2」、入場通知、モード説明を整理。描画ループやモデルを変更していない。
- CPUの中央優先の目標選択と専用定数を削除。移動可能なナビゲーション地点から選択する。独立したエリア専用エイム補正は存在しなかった。近距離エイム弱体化、コンボ継続判断、水分回復判断は維持。
- サーバーとソロは同じBattleSimulationを利用。位置にかかわらずレインボーは成功1回50BP、通常BPは従来の基本値とコンボ倍率。着地1回の重複加点防止を維持。
- 最新指定を優先し、RAINBOW_FLOP_SPEEDを1.25→1.5、RAINBOW_WATER_BONUSを20→50へ変更。通常A/Dの0.85を基準に1.5倍（旧通常速度比1.275）。Space・チュートリアルの周期は変更しない。
- レインボーの水分消費半減、水たまり通常回復20ポイント/秒、入水ボーナスの重複防止と最大100、ライフ1〜4/初期3、初期軽量画質を維持。
- 既存の壁押し付け対策のみ残す。2秒以上、壁の補正を受けて実移動がほぼない状態では加点しない。実際に0.08m移動すれば解除。短い接触、壁沿い移動、壁からの方向転換はコンボを継続。

- 両ステージ、魚・イカ、CPU・プレイヤー、通常・レインボー、A/D・Spaceについて位置依存の加点がないことを確認。
