# 捌かれるな！！

死んだふりで、死を回避せよ。業務用厨房のまな板に横たわる35cmの魚を操作し、料理人の包丁と捕獲を避けてシンクの排水溝へ逃げる、ブラウザ向け3Dゲームです。

## 起動

Node.js 20.19以上、または22.12以上（開発・検証はWindows / Node.js 24.21.0）。WebGLに対応したChrome、Edgeなどを使用してください。

```sh
npm install
npm run dev
```

ブラウザで **http://127.0.0.1:5173/** を開いてSTART。PowerShellで `npm.ps1` の実行が禁止されている場合は `npm.cmd install`、`npm.cmd run dev` を使用できます。ゲームの実行にインターネットは不要です。初回の依存パッケージ取得にはネット接続が必要です。

```sh
npm run build
npm run preview
```

ビルド結果は `dist/`。その中身を静的ホスティングへ配置できます。サブディレクトリ配置に対応しています。直接 `file://` で開く構成ではありません。公開時は `dist/` を使用してください。

## 操作と攻略

| 操作 | 効果 |
| --- | --- |
| A / Dを押す | 尾を打ち、カメラが向く方向へ跳ねる。左右移動ではない |
| A・Dを交互に約0.28秒間隔で押す | 推進ボーナスとコンボ。押しっぱなし・リピートは無効 |
| 空中でもう一度A / D | 2段目ジャンプ。3段目は不可 |
| マウス移動 | ポインターロック中はカメラ回転 |
| Esc、画面ドラッグ | ロックを解除し、ドラッグ操作に切り替え |
| マウスホイール | カメラ距離2.0～4.5m |
| タッチ端末 | 左右下のA/Dボタンで跳ね、他領域をドラッグして向きを変える |
| 入力を止める | 接地して十分に減速し、0.8秒間静止すると死んだふり |

Spaceはジャンプではありません。魚の移動はマウスで向きを決めてからA/Dで推進します。最初は入力を止めて料理人を観察してみてください。疑い度が下がると包丁を下ろして近づき、魚に手を伸ばします。**「今だ！」の表示中にA/Dを押すと奇襲成功**。2秒間のスタンと強い推進を得られます。早すぎると通常ジャンプ、遅すぎると捕獲されます。

金色の矢印に沿って、まな板から左へ移動し、狭い接続台を北（初期前方）へ渡ります。シンクの前縁を跳び越え、底に降りて光る排水溝に入ってください。シンク内の水で水分が回復します。台から床へ落ちると死亡します。包丁の赤い予告線を見たら、跳ねて軌道を外しましょう。

## 実装

- 固定版Three.js 0.180.0、Vite 7.3.7、ES modules。ライブラリはローカルにバンドル。
- 60Hz固定物理、最大5サブステップ、球とAABBの最近接点判定、小分割移動、上下左右の衝突処理。ジャンプ・摩擦・水分・スコアは仕様の数値に準拠。
- WAITING / CHASING / ATTACKING / SUSPICIOUS / APPROACHING / INSPECTING / STUNNEDのAI。発射時点の方向に進む包丁は線分スイープで命中・障害物判定。
- 52断面×32周方向の滑らかな魚メッシュ。鱗テクスチャ、濡れたclearcoat、エラ、左右の目、二叉尾、背びれ・胸びれ。頂点変形による全身のしなりと空中ひねり。横倒しの姿勢を維持。
- 身長約1.75mの関節式料理人。頭・手足・コート・帽子・エプロン・包丁と状態別アニメーション。魚を遮る場合は料理人を半透明化。
- PMREM環境反射、ACESトーンマッピング、影、金属の擦り傷と木目、非衝突の透明水面、200個の水滴プール、波紋プール、合成効果音。
- STARTから死亡・クリア・RETRYまで実装。最高スコア・最短時間をlocalStorageへ保存。保存が使えない場合もプレイ継続。
- HIGH / MEDIUM / LOWで解像度と影を変更。FPS表示と音ON/OFFを装備。

## ステージ到達性と仮定

仕様の調理台とシンクには0.7mの空白があるため、中心(-1.5,0.425,0.05)、サイズ(1.25,0.85,0.9)の接続台を追加しました。調理台上面と接続台上面はどちらもY=0.85。シンクの前縁はY=1.0です。

1段目ジャンプの上昇量は `2.6² / (2×9.8) = 約0.345m`。接続台からシンクの縁への0.15mの段差を越えられます。中央を充填する箱は置かず、底面Y=0.55と側壁だけでシンクを作りました。魚は底面上でY=0.615となり、排水溝まで移動できます。テストは初期位置から実際の入力・衝突・AIを動かしてクリアできることを確認しています。

死んだふりの0.8秒は、接地かつ速度0.15m/s未満の状態が続く時間として解釈しました。料理人は通常の台上と接続台を移動し、シンクの底には降りません。到達不能な魚には縁から包丁を投げます。

## テスト

```sh
npm test
npm run test:browser
npm run build
```

ブラウザテストは別ターミナルで `npm run dev` を起動してから実行します。既定はインストール済みMicrosoft Edgeをヘッドレスで使用します。Edgeがない環境では `playwright.config.js` の `channel` を利用可能なブラウザに変更してください。開発時限定の `window.__game` で検査と時間の進行を行います。製品ビルドではこのフックは除去されます。

実施結果：

- ロジックテスト10件成功：状態停止とリセット、入力間隔と2段ジャンプ、カメラ方向への推進、死んだふりとAI、奇襲の成功・失敗、球-AABB衝突、包丁スイープ、水分、通常入力でのステージ到達、死亡優先。
- Edge / Playwrightのブラウザテスト3件成功：タイトル→START→A/D→死んだふり→奇襲→GAMEOVER→RETRY→CLEAR、Space無効、キーリピート無効、描画設定、リサイズ、マウスドラッグを確認。タッチ端末のエミュレーションでA/D、水面下からのカメラ、localStorage保存不可時の継続も確認。未処理のページ例外なし。
- `tests/screenshots/` にタイトル、プレイ、奇襲、死亡、クリア、LOW設定の画像を保存し、魚の位置・姿勢・厨房・HUDを確認。
- `npm run build` 成功。依存パッケージ監査で既知の脆弱性0件。
- 配布用プレビューでもSTARTからの描画を確認。ページ例外なし、開発用検査フックが存在しないことを確認。

## 制約

外部GLB・HDRIは使用せず、すべてのモデルとテクスチャ・効果音を手続き的に生成します。料理人は簡略化した関節式モデルで、写真品質の人型ではありません。AOや被写界深度などの画面全体のポストエフェクトは導入していません。詳細な描画より操作と視認性を優先しています。

仕様の座標・速度を保った小さな厨房なので、最短経路を知るプレイヤーは約5～15秒でも脱出できます。目標の60～120秒を強制する待ち時間は設けていません。水分が低いまま逃げ続けると約66秒で乾燥します。

ヘッドレス検証はソフトウェアWebGLを使用したため、実機GPUでの30/60fps保証は行っていません。重い場合はLOWに切り替えてください。モバイル用の入力は実装しましたが、実際のスマートフォン実機での確認は行っていません。
